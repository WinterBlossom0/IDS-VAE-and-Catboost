On a single CPU thread, end-to-end processing with the detector takes 0.050\,ms per flow, compared to 0.018\,ms for raw CatBoost: the fused VAE and CatBoost graph accounts for 0.044\,ms (0.046\,ms as two separate graphs), the correction takes 0.00015\,ms, and the detector takes 0.0058\,ms. We timed each pipeline with a time in Table~\ref{tab:main} as ONNX Runtime 1.31 graphs and C++ code on one thread of an Intel Core Ultra 9 275HX, one flow per call from the extracted features to the final label, over the 100{,}000 consecutive flows in the middle of day 02-21 (98{,}562 Benign burst and 1{,}438 attack flows). Each time is the median of 4 passes; a full repeat gave the same order of the 16 pipelines and a framework time 1.3\,\% higher.
